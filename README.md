# ChordSnap

ChordSnap ist ein kleines Lernprojekt für eine mobile Web-App, die Musik über das Smartphone-Mikrofon aufnimmt und später erkannte Gitarrenakkorde anzeigen soll.

## Arbeitsweise

Wir entwickeln die App story-basiert in kleinen Inkrementen. Jede Story wird auf einem eigenen Branch umgesetzt und über einen Pull Request geprüft.

Aktueller Fokus: CS-001 Mikrofonberechtigung anfordern.
